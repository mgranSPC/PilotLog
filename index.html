Sync across devices

Your logbook is stored as a JSON file in a private GitHub repository on your account and kept in sync on every device where you set this up. Changes merge per entry, so you can log flights from any device.

One-time setup (about 2 minutes)
  1. Create a private repository on GitHub, e.g. pilotlog-data (check “Add a README” so the repo isn’t empty).
  2. Create a token the app can use: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Under Repository access choose Only select repositories and pick your data repo. Under Permissions → Repository → Contents choose Read and write. Generate and copy the token.
  3. Paste the token and repository below on each device.

The token is stored only on this device and is never included in backups or exports.
